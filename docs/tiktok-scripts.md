## Filming Tips

### Setup
- Shoot vertical (9:16 aspect ratio) — TikTok, Reels, and Shorts all native vertical
- Natural light is best: face a window. Ring light as backup for evening shoots
- Background: clean wall, workshop, or use TikTok's Green Screen effect

### Editing
- Use **CapCut** (free) or TikTok's native editor for text overlays
- Text is CRITICAL — most viewers watch muted. Every key point needs on-screen text
- Keep transitions fast: 2–3 second cuts max
- Add captions/subtitles via auto-caption feature

### Batch Production
- Film all 6 scripts in one session (1–2 hours total)
- Change shirts or backgrounds between scripts for variety
- Record 2–3 takes of each, pick the most energetic

### Posting Schedule
- Post during peak teen hours: **7–9am** (before school) or **7–11pm** (evening scroll)
- Best days: Tuesday, Thursday, Friday
- Space posts: 1–2 per day max to avoid burnout
- Reply to every comment within 60 minutes of posting
