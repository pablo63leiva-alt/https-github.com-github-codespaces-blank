## Section B: UTM Strategy

### Base URL
```
https://tradelift.surge.sh/quiz.html
```

### Parameter Breakdown

| Parameter | Purpose | Values |
|-----------|---------|--------|
| `r=` | Trade result match (permalinks result) | `electrician`, `welder`, `plumber`, `hvac`, `construction-manager` |
| `utm_source` | Platform origin | `instagram`, `tiktok`, `x`, `threads`, `snapchat` |
| `utm_medium` | Traffic type | `social` (always, for social shares) |
| `utm_campaign` | Campaign grouping | `quiz_share` (all result-share traffic) |
| `utm_content` | Trade variant (for analytics grouping) | Same as `r=` value: `electrician`, `welder`, etc. |
| `utm_term` | (Optional) A/B test variant | `emoji_heavy`, `clean`, `challenge`, etc. |

### Tracking in Analytics

1. **All quiz-share traffic:** Filter by `utm_campaign = quiz_share` in GA4/Plausible Acquisition reports
2. **Per-trade breakdown:** Group by `utm_content` to see which trade result gets shared most (and which drives the most completions)
3. **Per-platform performance:** Group by `utm_source` to see which platforms convert quiz-shares into new quiz-takers
4. **A/B testing:** Add `&utm_term={variant}` — compare `emoji_heavy` vs `clean` caption performance
5. **Funnel tracking:** Quiz share → new quiz start → completion → email opt-in. Track drop-off at each stage using the `r=` param as a cohort marker.

### Step-by-Step: Platform-Specific Cropping

#### Instagram (Feed Post — 1080×1080 square)
1. Open the OG card (1200×630) in Canva or any free image editor
2. Crop to 1080×1080 — center the trade name and salary pill
3. If adding a name overlay: place white bold text at center-bottom, `text-shadow: 2px 2px 4px rgba(0,0,0,0.8)` for readability on the dark gradient
4. Export as PNG, 1080×1080

#### Instagram Stories / TikTok (1080×1920 vertical)
1. Start with the OG card (1200×630)
2. Place it in the center of a 1080×1920 canvas with dark background (#1a1a1a or match the gradient)
3. Leave room above for hook text: "I'm an Electrician ⚡ — what's your trade?"
4. Leave room below for the quiz link or "Swipe up" / "Link in bio" text
5. Add user's name overlay if personalizing: center-bottom, white bold sans-serif, dark shadow

#### X / Twitter (1200×630 — native)
1. Use the OG card as-is (already 1200×630)
2. Optionally overlay result text: "I'm a Plumber 🔧" in white bold at center-bottom
3. Export as PNG — X renders 1200×630 natively in timeline

#### Threads (1080×1350 — 4:5 ratio)
1. Crop the OG card to 1080×1350 — focus on the trade name and salary
2. Add name overlay if personalizing
3. The 4:5 ratio takes up more feed space = more attention

#### Snapchat (1080×1920)
1. Same as TikTok layout: OG card centered, hook text above, CTA below
2. Add Snap link sticker pointing to the UTM'd quiz URL

### Name Overlay (Personalizing for Users)

If a user wants their name on the share image:
- **Font:** Bold sans-serif (Montserrat, Inter, or system bold)
- **Color:** White (#FFFFFF) with dark text-shadow (2px 2px 4px rgba(0,0,0,0.8))
- **Position:** Center-bottom of the card, below the salary pill
- **Size:** 36–48px on 1080px-wide canvas
- **Example:** "JAKE'S RESULT" or "YOUR NAME → ELECTRICIAN ⚡"

### Free Tools (No Paid Required)
- **Canva** (free tier) — drag-and-drop cropping, text overlay, templates for each platform
- **Instagram Story Editor** — native in-app text and sticker tools
- **CapCut** (free) — can create static images with text overlays for video thumbnails
- **Phone photo editor** — native crop + text tools work fine for quick edits

## Section D: 3 Share-Loop Tactics

### Tactic 1: The Challenge

**Name:** #TradeChallenge
**How it works:** Post your quiz result, challenge followers to take the quiz and share theirs. Create a branded hashtag to track the loop.

**Exact Post Copy:**

> I just took the TradeLift quiz and got Electrician ⚡ — $60K–$80K, no degree, no debt. Not bad for a 2-minute quiz.
>
> Here's the challenge: take the quiz, post your result, and tag 3 friends who need to see this. Use #TradeChallenge so we can find each other.
>
> I'll feature the best results on my story this week.
>
> 🔗 [quiz link with UTM]

**Example full UTM link:**
`https://tradelift.surge.sh/quiz.html?r=electrician&utm_source=tiktok&utm_medium=social&utm_campaign=quiz_share&utm_content=electrician`

**How it creates a loop:**
1. Original post triggers 3 tags → those 3 take the quiz → post their results → tag 3 more each
2. Each result post drives curiosity clicks from the poster's followers
3. The branded hashtag (#TradeChallenge) creates a searchable feed of UGC
4. Featuring results on stories incentivizes participation

**Best platforms:** TikTok (challenge format native), Instagram Stories (tag + reshare)

### Tactic 2: The Duet/Stitch

**Name:** Trade Result Duet
**How it works:** Film a duet/stitch prompt asking viewers to take the quiz and compare results. Stitch format works best — you show your result, then cut to the viewer's implied reaction.

**Exact Post Copy (Stitch prompt):**

> "I just found out I'm an Electrician ⚡ — $60K–$80K and no degree. I literally gasped. Stitch this with YOUR result and let's compare. I want to see who got what."
>
> Quiz link in bio 👇 Tell me in the comments if it was accurate.

**Example full UTM link:**
`https://tradelift.surge.sh/quiz.html?r=electrician&utm_source=tiktok&utm_medium=social&utm_campaign=quiz_share&utm_content=electrician`

**How it creates a loop:**
1. Stitch invites direct video response — each stitch is a new post reaching a new audience
2. "Let's compare" creates a conversation thread in comments
3. Viewers who stitch expose the original creator's content to their own followers
4. Each stitched response is essentially a testimonial/endorsement of the quiz

**Best platforms:** TikTok (stitch is native), YouTube Shorts (similar format)

### Tactic 3: Answer in Comments

**Name:** Drop Your Trade
**How it works:** Post your result and ask followers to answer in the comments. The comment section becomes the engagement engine — more comments = more algorithmic reach = more people see the post = more quiz completions.

**Exact Post Copy:**

> I'm an Electrician ⚡ — $60K–$80K/yr, no degree required. The TradeLift quiz said this is my trade and honestly? It fits.
>
> DROP YOUR RESULT IN THE COMMENTS 👇
>
> I'll reply to every single one. If you haven't taken it yet — 2 minutes, link in bio. No signup required, just results.

**Example full UTM link (in bio):**
`https://tradelift.surge.sh/quiz.html?r=electrician&utm_source=instagram&utm_medium=social&utm_campaign=quiz_share&utm_content=electrician`

**How it creates a loop:**
1. "Drop your result" is a low-barrier CTA — everyone has an answer after taking the quiz
2. Replies to comments ("Electrician twins!") boost engagement metrics → algorithm pushes post to more feeds
3. Users who see the comment section activity get curious → take the quiz themselves → come back to comment
4. Pinning the top comment with a result creates social proof that drives more participation

**Best platforms:** Instagram (comments drive feed ranking), Threads (conversational format), X (thread replies expand reach)
